Entry for the [make.fun bounty "The Funniest Sick-Day Excuse"](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

> I lost my voice arguing with the automated phone menu for 47 minutes last night — it won, and now I can only communicate in hold music.

## How it works

`main.py` runs on Python 3 with the standard library only, and writes the line above to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR`, falling back to `/output` when the variable is unset. The output is exactly 135 characters on a single line, with no trailing newline.

Nothing here reaches the network or consults any outside source; the script only composes one fixed string and drops it into the requested folder.
